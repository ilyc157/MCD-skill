# 麦乐配 · 麦当劳点餐搭配 Skill

**随口一句话，开启幸福金拱门。**

说清几个人、多少钱、谁忌口、谁在减脂。它把菜单翻一遍、套餐拆开、价格核过，
给你几套能直接照着点的方案——控卡的按热量卡住，追性价比的往低处顶，一人一套，互不将就。
**你确认，它才下单。**

适用于 WorkBuddy。数据全部来自麦当劳中国官方 MCP，不预置静态菜单：
同城不同店同款汉堡存在差价，写死在文档里的价格必然是错的。

---

## 适合谁用

- 一个人吃饭想控热量，又不想逐条翻营养表
- 一群人聚餐，有人忌口、有人减脂、预算还有上限
- 想比默认套餐点得更省，懒得自己凑组合
- 不想为「今天吃什么」再花十分钟

## 安装

**1. 放进技能目录**

```bash
git clone https://github.com/ilyc157/MCD-skill.git ~/.workbuddy/skills/mcd-meal-planner
```

**2. 获取麦当劳 MCP token**

打开 <https://open.mcd.cn/mcp>，手机号登录 → 控制台 → 激活，免费。
接入地址是根路径 `https://mcp.mcd.cn`（加 `/mcp` 后缀会 404）。

**3. 把 token 配进去**，两种方式任选：

- 写进 `~/.workbuddy/mcp.json`，给麦当劳那个 server 加请求头
  `"Authorization": "Bearer <你的token>"`。可直接照抄 [mcp-config.example.json](mcp-config.example.json)，
  把其中的 `${MCD_TOKEN}` 换成你的 token
- 或者设环境变量 `export MCD_TOKEN=<你的token>`

**4. 验证**

对 WorkBuddy 说：

> 帮我点麦当劳，一个人，预算 30 以内

能出卡片就是通了。报「找不到 token」就往回看第 3 步。

## 怎么用

不用记参数，把要求说成人话就行。

**一个人，控卡**

> 帮我点麦当劳，预算 35，热量别超过 700，要带饮料

**一群人，口味不一致**

> 我们三个人聚餐，有一个人不吃辣、在减肥，总预算 130

**外送到公司**

> 点麦当劳外送，送到科技园，两个人，80 块

它会先确认缺的信息（人数、预算、忌口、取餐方式、位置），然后直接给方案。
不满意可以说「换一批」，只改条件重算，不用重新报一遍需求。

---

## 你会看到什么

多套搭配方案，每套包含：

- **具象的方案名** ——「双层吉士高蛋白套」，不是「方案 A」
- **逐行商品清单** —— 菜名、份数、千卡；套餐已拆成单品
- **价格看板** —— 实付金额、立省多少、人均
- **营养看板** —— 合计热量、蛋白、钠，超限标红
- **依据** —— 为什么这样配，每条都指得回具体数字

多人且有人控卡时，清单会按「轻食 / 照常 / 共享」分组，每组标明这是几个人的、每人多少千卡。

## 边界

**没被明确选择，不下单。** 出现「下单」两个字才算授权。下单接口单账号每天有次数上限，
取消订单不退还额度——所以它不会拿真实订单做试验。

**查不到热量就写「未收录」。** 当季新品和部分甜品不在官方营养表里，这类商品不参与控卡计算，
卡片上标灰，不填 0，也不拿相似商品的热量凑数。

**不混用到店价和外送价。** 到店自取和麦乐送是两套菜单，同款可能差一块钱，
部分商品（比如随心配）只有到店有。取餐方式说错，价格就是错的。

**做不到的也说清楚。** 团餐满 300、满 500 的折上折不在方案内，要在核价之后单独叠加；
门店库分三套（到店自取 / 得来速 / 外送），编号不通用；查店给的是关键词解析点到门店的
直线距离，不作为「离你多远」的依据；只做麦当劳。
